## About me
I am a postdoctoral researcher at the German Aerospace Center (DLR) working with WebAssembly and Ada. 
More about my work at [tintoedoardo.github.io](https://tintoedoardo.github.io/). 

Some of my open-source works: 
1. A toy [example](https://github.com/TintoEdoardo/checkpoint_and_restore_examples) of how to instrument WebAssembly modules to perform _live migration_ across heterogeneous hosts. A more extensive discussion is provided [here](https://www.sciencedirect.com/science/article/pii/S1383762125002048).
2. Instructions on [how to compile Ada code to WebAssembly](https://github.com/TintoEdoardo/gnat-llvm-wasm) using GNAT-LLVM. 
3. A guide to [embed a WebAssembly interpreter into a Ravenscar-compliant Ada application](https://github.com/TintoEdoardo/embedded-wasm-over-ada), using the [WebAssembly interpreter](https://github.com/DLR-FT/wasm-interpreter) developed at DLR.
